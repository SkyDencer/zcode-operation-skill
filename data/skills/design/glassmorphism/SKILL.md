## When to use

Use when creating modern glass-like UI elements, implementing backdrop blur effects, or designing translucent card components with depth.

## Instructions

1. Use backdrop-filter: blur() for frosted effect
2. Add semi-transparent white backgrounds
3. Include subtle borders for depth
4. Layer multiple glass elements
5. Ensure text contrast on blurred backgrounds
