## When to use

Use when creating consistent spacing systems, defining token scales, or establishing visual rhythm across UI components.

## Instructions

1. Use 4px or 8px base grid
2. Create spacing scale: 4, 8, 12, 16, 24, 32, 48
3. Use CSS custom properties for tokens
4. Apply consistent gap values
5. Test spacing at different breakpoints
