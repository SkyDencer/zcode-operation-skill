## When to use

Use when building responsive layouts, implementing mobile-first CSS, choosing breakpoint values, or creating adaptive component designs.

## Instructions

1. Start with mobile styles first
2. Use min-width media queries
3. Set breakpoints at content needs
4. Use container queries for components
5. Test on real devices
