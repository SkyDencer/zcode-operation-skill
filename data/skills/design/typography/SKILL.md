## When to use

Use when establishing typographic hierarchies, selecting font families, setting responsive type scales, or optimizing web font delivery.

## Instructions

1. Choose max 2 font families
2. Use modular scale for type sizes
3. Set line-height to 1.5 for body text
4. Use clamp() for responsive scaling
5. Subset and preload web fonts
