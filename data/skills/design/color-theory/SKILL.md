## When to use

Use when building color systems, choosing color palettes, ensuring accessibility compliance, or creating consistent design token sets.

## Instructions

1. Start with a base hue and build palette
2. Ensure 4.5:1 contrast for text
3. Use semantic tokens: primary, secondary, surface
4. Test with color blindness simulators
5. Document color usage in design system
