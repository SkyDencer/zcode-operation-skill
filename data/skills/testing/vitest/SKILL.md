## When to use

Use when testing Vite-based frontend projects, writing unit tests for utilities, testing React components, or mocking API calls in tests.

## Instructions

1. Configure vitest.config.ts
2. Use describe/it/expect pattern
3. Mock modules with vi.mock()
4. Run with --coverage for reports
5. Use testcontainers for integration tests
