## When to use

Use when writing Laravel tests with Pest PHP, creating feature test suites, asserting database state, or generating test coverage reports.

## Instructions

1. Create tests with pest command
2. Use expect() for expressive assertions
3. Test HTTP responses with assertStatus()
4. Assert database state with assertDatabaseHas()
5. Generate coverage with --coverage flag
