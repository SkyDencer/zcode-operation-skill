## When to use

Use when following TDD methodology, writing tests before code, establishing test naming conventions, or teaching TDD practices to a team.

## Instructions

1. Write failing test first (Red)
2. Write minimum code to pass (Green)
3. Refactor with confidence (Refactor)
4. Use descriptive test names
5. Keep tests independent and fast
