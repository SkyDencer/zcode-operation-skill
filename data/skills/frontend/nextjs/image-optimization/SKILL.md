## When to use

Use when displaying images in Next.js applications, optimizing image load times, or serving responsive images across devices.

## Instructions

1. Use next/image instead of <img> tag
2. Set proper width and height attributes
3. Configure remotePatterns in next.config.js
4. Use priority prop for above-fold images
5. Enable blur placeholder for LQIP
