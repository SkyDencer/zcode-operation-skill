## When to use

Use when building Next.js 13+ applications with the App Router, creating nested layouts, implementing loading states, or organizing routes with route groups.

## Instructions

1. Create page.tsx for each route segment
2. Use layout.tsx for shared UI
3. Add loading.tsx for skeleton screens
4. Handle errors with error.tsx
5. Use route groups with () parentheses
