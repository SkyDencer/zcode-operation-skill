## When to use

Use when designing reusable component APIs, choosing between composition patterns, or structuring complex component hierarchies.

## Instructions

1. Prefer Compound Components for flexible APIs
2. Use Render Props for cross-cutting logic
3. Apply HOCs sparingly for wrapper behavior
4. Use Control Props for parent-controlled state
5. Follow Hook Rules: only at top level
