## When to use

Use when writing unit tests for React components, testing custom hooks, simulating async behavior, or verifying UI interactions.

## Instructions

1. Query by user-facing labels and roles
2. Test behavior not implementation
3. Use @testing-library/react-hooks for hook tests
4. Mock APIs with MSW or jest.fn()
5. Avoid testing internals and implementation details
