## When to use

Use when managing complex application state, sharing data across many components, or replacing prop drilling with scalable state solutions.

## Instructions

1. Keep state as close to usage as possible
2. Use Zustand for global state without boilerplate
3. Use Jotai for atomic state management
4. Reserve Redux for complex state transitions
5. Avoid context for frequently changing state
