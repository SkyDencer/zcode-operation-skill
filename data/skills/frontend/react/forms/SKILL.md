## When to use

Use when building complex forms with validation, handling form state efficiently, or implementing multi-step form wizards.

## Instructions

1. Use React Hook Form for performance
2. Validate with Zod schema
3. Prefer uncontrolled components where possible
4. Handle submission with async handlers
5. Show field-level validation errors
