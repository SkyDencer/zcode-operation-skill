## When to use

Use when building React components with state management, side effects, context sharing, or extracting reusable logic into custom hooks.

## Instructions

1. useState for component-local state
2. useEffect for side effects and subscriptions
3. useContext for cross-component data sharing
4. useReducer for complex state logic
5. Extract custom hooks for reusable logic
