## When to use

Use when validating incoming request data, creating reusable validation rules, or formatting validation error responses for API consumers.

## Instructions

1. Create Form Request classes for complex validation
2. Define custom Rule objects for reusable rules
3. Use Rule::in() for enum-style validation
4. Format errors consistently in API responses
5. Add custom error messages for better UX
