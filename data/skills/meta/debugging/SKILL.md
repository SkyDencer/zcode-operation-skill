## When to use

Use when investigating bugs, analyzing stack traces, detecting memory leaks, or systematically debugging application issues.

## Instructions

1. Reproduce the issue consistently
2. Check console for errors and warnings
3. Use breakpoints at suspected failure points
4. Analyze stack traces top-down
5. Isolate variables to find root cause
