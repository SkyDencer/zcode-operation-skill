## When to use

Use when reviewing pull requests, establishing code review processes, checking for security issues, or providing constructive feedback.

## Instructions

1. Review one concern at a time
2. Ask questions not commands
3. Check for security vulnerabilities
4. Look for performance bottlenecks
5. Praise good practices too
