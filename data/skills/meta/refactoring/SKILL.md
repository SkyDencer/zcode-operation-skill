## When to use

Use when improving code readability, reducing complexity, eliminating duplication, or preparing code for new features without changing behavior.

## Instructions

1. Write tests before refactoring
2. Make small incremental changes
3. Extract functions for clarity
4. Rename variables for intent
5. Run tests after each change
