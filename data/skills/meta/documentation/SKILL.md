## When to use

Use when writing project documentation, creating API references, maintaining changelogs, or onboarding new contributors to a codebase.

## Instructions

1. Start README with setup instructions
2. Document public APIs with examples
3. Use diagrams for complex flows
4. Keep changelog up to date
5. Include contributing guidelines
